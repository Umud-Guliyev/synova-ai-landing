---
name: nova-add-section
description: Add or redesign a section or component in the NOVA kit so it matches the design system. Use when the user asks for a new section, block, card, grid, or component.
---

Follow `ai/playbooks/add-section.md`, after reading `ai/design-system.md` and checking `ai/components.md` for an
existing component that already does it. After adding a component, run `npm run catalog` to update the catalog,
then `npm run check`.
