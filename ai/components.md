### `<Reveal />` · `src/components/nova/reveal.tsx`

Fades and lifts its children in the first time they scroll into view. The hidden start state lives in CSS behind the `.nova-js` class, which the inline script in layout.tsx sets before first paint. With JavaScript off the class is never added, so the content simply renders visible. The observer is attached from a ref callback rather than an effect, so the element is watched the moment it mounts and cleaned up when it unmounts.

## Motion

### `<Stagger />` · `src/components/nova/stagger.tsx`

Scroll-triggered stagger. Watches its items with one IntersectionObserver and flips `data-nova-shown` on each as it enters the viewport; CSS in globals.css (`[data-nova-item]`) does the motion, with the delay taken from `--nova-i` × `--nova-stagger`. No layout wrappers are added, reduced motion shows everything at once, and with JavaScript off nothing is hidden.

Used on: `/careers/[slug]`

| Prop | Type | Notes |
| --- | --- | --- |
| `children` (required) | `ReactNode` |  |
| `mode` | `"stack" \| "grid"` | "stack" (default): items come in one after another in DOM order — eyebrow, heading, text, buttons, media. Items are the descendants marked `data-nova-item`, or the direct children when none are marked. "grid": the direct children are cards; each one reveals when it scrolls in, delayed by its column, so every row sweeps left to right at any column count. |
| `delay` | `number` | Extra delay before the first item, in ms (e.g. hero content after the nav). |
| `trigger` | `"scroll" \| "load"` | "scroll" (default): items reveal as they enter the viewport (needs JS). "load": pure-CSS entrance that starts on first paint, without waiting for JavaScript. Use it for the block at the top of a page so the main headline (the LCP element) isn't held back by hydration. Items then need their order in the markup: `style={itemIndex(n)}` (the first item may omit it). |
| `as` | `ElementType` |  |
| `className` | `string` |  |
| `style` | `CSSProperties` |  |
| `id` | `string` |  |

### `<SmoothScroll />` · `src/components/nova/smooth-scroll.tsx`

Site-wide smooth scrolling (Lenis) for mouse wheel and trackpad. Touch keeps native scrolling, `prefers-reduced-motion` turns it off, in-page anchors (`#section`, `#` = top) glide instead of jumping, and it pauses while anything locks the page with `overflow: hidden` (menus, modals). Mount once, in the root layout. Exposes the instance as `window.novaLenis`.

| Prop | Type | Notes |
| --- | --- | --- |
| `lerp` | `number` | Smoothing strength per frame (0–1). Lower = softer, longer glide but more lag behind the wheel/trackpad; higher = snappier. 0.1 is the NOVA feel. |
